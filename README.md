# HarrisCert

A complete Lean 4 + Mathlib proof that Harris's polarization constant 3√3/4 is attained for a symmetric bilinear
form on L^∞(𝕋). The mathematics is in `../harris_sharp.tex`.

## The theorem

`Challenge.lean` states it with Mathlib definitions only:

```lean
theorem Polarization.harris_constant_attained :
    IsGreatest {x : ℝ | ∃ f ∈ UnitBall, ∃ g ∈ UnitBall, x = ‖φ f g‖} 2 ∧
    IsGreatest {x : ℝ | ∃ f ∈ UnitBall, x = ‖q f‖} (8 / (3 * Real.sqrt 3))
```

Here:

- 𝕋 = `AddCircle (2π)` with normalized Haar measure.
- `a f k = fourierCoeff f (-k)`.
- `φ f g = a₀(f)a₃(g) − 2a₁(f)a₂(g) − 2a₂(f)a₁(g) + a₃(f)a₀(g)`.
- `q f = φ f f`.
- `UnitBall` is the set of a.e.-strongly measurable `f : 𝕋 → ℂ` with `‖f t‖ ≤ 1` for all `t`.

So ‖φ‖ = 2 and ‖q‖ = 8/(3√3), both attained. Hence ‖φ‖ = (3√3/4)‖q‖.

`Solution.lean` proves it by reduction to `Harris.harris_main` (`HarrisCert/Main.lean`).

## Trust base

```
#print axioms Polarization.harris_constant_attained
-- [propext, Classical.choice, Quot.sound]
```

The proof uses no `sorry` and no `native_decide`. The computational certificates are checked by the kernel with
`decide +kernel`.

## Structure

| files | content |
|---|---|
| `Challenge.lean`, `HarrisCert/Statement.lean`, `Solution.lean` | the statement (identical definitions in both), and the reduction to `harris_main` |
| `Bridge*.lean` | Fourier coefficients and the unit ball; rotations, reflection, phase; Bessel; `h₀` and its coefficients |
| `Assembly.lean` | the global reduction (Lemma 10): from `LocalThm` and the global step to the main theorem |
| `Defs`, `Q3`, `Sound`, `Poly`, `Cells*`, `Circle`, `Nbar*Sound`, `Kernel.lean`, `Core/` | the global step: soundness of the branch-and-bound checker and of the bound N̄ ≥ N |
| `Data/`, `Leaves/`, `Cover0–3.lean`, `GlobalStep.lean` | the global certificate, generated by `../julia/gen_lean.jl`; one `decide +kernel` theorem per leaf (2627 leaves) |
| `Local1–6.lean` | the local theorem: decomposition `g = h₀(1 + x + iy)`, the basic identity, Fourier coefficients of `1/(z+r)` etc. by recurrences, the Gram matrix over ℚ(√3), Bessel's inequality in L²(ρ) |
| `Data/LocalData.lean` | exact 7×7 data over ℚ(√3) (generated by `../julia/local_cert.jl`), with matrix identities and an LDLᵀ checked by `decide +kernel` |
| `Local7.lean` | the finite-dimensional core inequality (completing the square) |
| `Local8–10.lean` | the Λ₂ bound: polynomials over ℚ(√3), a kernel-checked positivity test on 64 cells for each half circle, and evaluation |
| `Local11–14.lean` | coordinates, the cross term, alignment (minimizer, vanishing derivative, rotation), and the final estimate `M + Re q ≥ 2εX − βX² ≥ 0` for `X ≤ X₀ = 7/10000` |
| `Main.lean` | `harris_main` |

The local theorem is formalized with cruder constants than in `../harris_sharp.tex`:

- ε = 7/50;
- `Re q(A x) ≥ −6(X/m)²` with `m = 2r(1−r)²`, in place of `L₁₁⁻`;
- Λ₂(ε) ≤ 230.

This gives β ≤ 400 and X₀ = 2ε/400 = 7/10000. The global certificate was regenerated for this X₀.

## Building

```
lake exe cache get     # Mathlib build cache
lake build             # the kernel checks of the certificates take several minutes
```

Each Lean process that imports Mathlib uses several GB of memory, so limit `LEAN_NUM_THREADS` (for example to 4–6)
to avoid running out of memory.

`.lake/` (7 GB) is marked as ignored for Dropbox.
